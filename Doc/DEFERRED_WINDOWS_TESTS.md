# Отложенные ручные проверки Windows

Здесь хранится только минимальный список проверок, которые нельзя достаточно надёжно закрыть
кодом, автоматическими тестами или review diff. Некритические проверки выполняются единым
acceptance-прогоном на указанном ближайшем барьере готовности. Перед прогоном список необходимо
пересмотреть, объединить пересечения и удалить либо пометить `obsolete` уже доказанные пункты.

## 50% — диагностика Tauri в packaged UI

### PR #53 — блокировка смены проекта активной Terminal-командой

- **Изменение / PR:** PR #53, отображение backend-причины ошибки открытия проекта.
- **Проверить вручную:** при активной долгой Terminal-команде попытаться открыть другой проект;
  Project Explorer должен показать точную backend-диагностику рядом с локализованным сообщением.
- **Почему автоматизации недостаточно:** component regression подтверждает рендер переданной строки,
  но не фактическую форму ошибки, которую packaged Tauri доставляет frontend на Windows.
- **Барьер:** 50%.
- **Статус:** `pending`.
- **Минимальный сценарий:** включить этот пункт в объединённый сценарий барьера; отдельный прогон PR
  не требуется. Запустить долгую команду, выбрать другой проект и сохранить точный текст ошибки.

### Текущий PR — диагностика файловых операций и Backup Manager

- **Изменение / PR:** текущий PR, сохранение backend-диагностики для read/save/create/delete,
  чтения списка backup и restore.
- **Проверить вручную:** вызвать одну безопасную stale-state ошибку восстановления backup и убедиться,
  что диалог показывает не только общее сообщение, но и точную backend-причину.
- **Почему автоматизации недостаточно:** unit-тест подтверждает форматирование строковых и `Error`
  значений, однако форму rejected IPC value и его отображение в установленном Windows WebView
  надёжно подтверждает только packaged-прогон.
- **Барьер:** 50%.
- **Статус:** `pending`.
- **Минимальный сценарий:** открыть Backup Manager, выбрать backup, изменить соответствующий файл
  внешним редактором и нажать «Восстановить»; записать точный текст, не включая персональные пути.
