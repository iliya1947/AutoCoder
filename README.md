# AutoCoder

AI-first среда разработки, способная автономно работать с программными проектами: анализировать код, создавать и изменять файлы, выполнять команды, запускать проверки, исправлять ошибки и доводить задачу до рабочего результата.

## Описание проекта

AutoCoder проектируется как независимая среда, центральным элементом которой является AI-оркестратор.

- **Стек технологий:** React + Tauri (Frontend) + Python (Backend) + Monaco Editor + SQLite + Ollama (локальные LLM).
- **Первая специализация:** Поддержка разработки и интеграции с **COMSOL Multiphysics 6.4.429** (Java API / Java Shell / Methods).

## Структура проекта

- `Doc/` — документация, проектная память и состояние разработки.
  - `Doc/PROJECT_MEMORY.md` — долговременная память проекта (цели, архитектура, стек).
  - `Doc/PROJECT_STATE.md` — текущее состояние разработки, выполненные задачи и планы.
- Подробные инструкции для ИИ-ассистентов находятся в файле `Doc/AGENTS.md` (в процессе создания).
